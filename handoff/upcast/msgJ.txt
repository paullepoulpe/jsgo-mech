j2go: typed collections for declarations with a wildcard `? extends X` (List<? extends JSType> is a *TList[*JSType])

Rule "typed collections", tenth slice (Ctx.typedArg): a type argument `? extends X` is X. A
declaration List<? extends X> reads X values, and only a collection made for a declaration
with element type X enters it (the flow rule compares the type arguments: a List<Y> of a
subclass Y is another typed list and keeps the declaration erased), so it holds a *TList[X].
`?` and `? super X` have no typed collection. J2GO_COLLS_NOWILDCARDS=1 is the previous rule.
