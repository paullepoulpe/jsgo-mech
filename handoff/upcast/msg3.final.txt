j2go: a string literal or a new object passed for an Object parameter is passed bare

Rule "bare arguments" (Conv.bare, ExprEmitter.argAs; J2GO_NOBARE=1 gives the previous
translation). From the pressure test's prototype P3.

An argument for an Object parameter (or an element of Object...) that cannot be null needs
no test for null: a string literal, or a new object of a class without subclasses (whose
pointer is the object).
    sb.append_Object(strobj_("x"))        ->  sb.append_Object("x")
    list.add(obj_(new_Entry(k, v)))        ->  list.add(new_Entry(k, v))
Go converts the value to the interface value that strobj_ / obj_ return for a value that is
not null. Only arguments are changed: there the parameter's type any gives the expression
its type (in `x := "a"` or as a receiver it would not). A constant string in an interface
allocated nothing before either, so this changes how the code reads, not what runs.
