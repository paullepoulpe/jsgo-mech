j2go: a class without subclasses becomes an interface it implements as Go converts it (static upcast; no box, no type assertion)

Rule "static upcast" (Conv.upcast, new file Conv.java for the conversions that need no box;
J2GO_NOUPCAST=1 gives the previous translation). From the pressure test's prototype P1.

A conversion from a class to an interface that the class implements is not checked in Java.
The erased translation boxed the value and asserted the interface: icast_I(obj_(v)). For a
class without subclasses the pointer is the object itself (there is no most derived object to
find), so the interface value that Go's conversion makes is the one the assertion made.
null must stay the nil interface:
  - `this` and a new object are never null: NodeTraversal_Callback(this), List(new_ArrayList_0())
  - any other value goes through a generated function, one per pair of types in g_0casts.go:
      func Compiler_as_SourceExcerptProvider(v *Compiler) SourceExcerptProvider {
          if v == nil { return nil }
          return v
      }
A class of the program must have every method of the Go interface (Ctx.implementsInGo); for
a class of the runtime (*ArrayList, *ImmutableList, *ImmutableSet, the views of typed
collections -> List / Set / Collection / Iterable / Map) the Go compiler checks the pair:
179 functions, all compile. An interface that no conversion asserts any more has no icast_.

icast_I(...), 247 conversions of a class to an interface: a class with subclasses 132 (its
value may be a part of a larger object: icast_I(v.self())); a program class whose Go type
lacks a method of the Go interface 54 (a method implementing the methods of two interfaces
is in one group only: TypedScope -> StaticTypedScope 17, the Predicate classes of NodeUtil);
