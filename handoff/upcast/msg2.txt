j2go + runtime: checkNotNull / requireNonNull are Go generic functions of the argument's static type (no box, no cast back)

Rule "typed non-null checks" (Conv.nonNull, ExprEmitter.call; runtime rt_conv.go;
J2GO_NONONNULL=1 gives the previous translation). From the pressure test's prototype P2.

<T> T checkNotNull(T, ...) of Guava's Preconditions and <T> T requireNonNull(T, ...) of
java.util.Objects return their first argument. The erased translation boxed the argument and
cast the result back:
    this.compiler_ = cast_[*Compiler](Preconditions_checkNotNull(obj_(compiler)))
Now the call is a Go generic function of the argument's static type, which tests the value
against the null of that type and returns it:
    this.compiler_ = Preconditions_checkNotNull_T(compiler)
_T ([T comparable]) is for a class, an interface or a handle (null is nil, the zero value),
_Str for a String (null is the null string; no call of the program passes a String today,
the selftest does). The functions throw what the functions taking an
object throw (NullPointerException without a message, or with the formatted message). The
message arguments are converted as before.
