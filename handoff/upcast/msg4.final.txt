j2go + runtime: message arguments of Preconditions checks are passed at their own type and made objects only when the check fails

Rule "message arguments" (Conv.msgArg, Conv.handleMsg, ExprEmitter.argAs / call; runtime
canon_ and the _H functions in rt_conv.go; J2GO_NOMSG=1 gives the previous translation). From
the pressure test's prototype P4.

An Object parameter after the first of Preconditions.checkState / checkArgument /
checkNotNull is only formatted, and only when the check fails. The erased translation made
every such argument an object first, on the path that does not fail:
    Preconditions_checkState_boolean_String_Object(ok, "bad type %s", obj_(t))
    Preconditions_checkState_boolean_Object(n.isName(), n.box_())
Now a String or a pointer to a class is passed at its own type (Go converts it to the
interface without a test or a call), and the runtime makes it the object that the erased
translation passed before it formats the message: canon_ gives null for the null string and
for a nil pointer, and the most derived object (self()) for a pointer to a class with
subclasses; it is the identity on an object. lenientToString_ and the checks with one Object
message call it. A handle (a Node) as the one message argument of checkState / checkArgument
(with or without a template) calls a variant generic in the handle type, which boxes the
handle when the check fails:
    Preconditions_checkState_boolean_String_Object(ok, "bad type %s", t)
    Preconditions_checkState_boolean_Object_H(n.isName(), n)
Interfaces, primitives, typed collections and value types are converted as before.

595 calls take a handle (checkState(b, Object) 361, checkArgument(b, Object) 140, with a
template 67 + 27); 205 other arguments are passed at their type.

Tests: rt_conv_test.go (TestConvCanon: nil pointers, the null string, a null handle, an
object; TestConvMessages: the message of each kind of call equals the message of the boxed
call, checkNotNull of each kind). Selftest: lang/Unboxed.java messages() (a class with and
without subclasses, null of each, Strings, a toString that throws, more arguments than
placeholders, the argument's toString not called when the check holds).
