# The classes valobj turns into Go values, and what the tool cannot check cheaply, argued by
# hand with the lines of go/closure it rests on (line numbers as of the commit before the step;
# the Java classes are in com/google/javascript/jscomp/parsing/parser/util).
#
#   class C           C becomes a value. The tool checks its shape, immutability, identity-freedom
#                     and the mechanical part of null-freedom (see main.go), and stops if one fails.
#   field D.f         a field of type C in class D, argued here to be assigned by every constructor
#                     of D before anything reads it. The tool checks that every write of it is
#                     `this.f = x` in an init_/finit_ method of D (x is an expression of type *C,
#                     which the tool shows is never nil).
#   field+ D.f        the same, with writes outside D's constructors too (argued here).
#   nullable D.f      a field of type C that may be null: it stays a pointer (to a private copy).
#                     The tool checks it is only assigned a value, compared with nil, or
#                     dereferenced on the spot. No zero value stands for null.
#
# A field of a listed class's type that is not listed here stops the tool.
